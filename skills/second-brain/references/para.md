# PARA as a logical method

PARA originates with Tiago Forte. This skill is an independent implementation, not an official or affiliated product. [Method source](https://fortelabs.com/blog/para/).

| Placement | Classification question | Example |
|---|---|---|
| Projects | Is there a finite outcome to achieve? | Launch a portfolio |
| Areas | Is there an ongoing responsibility or standard? | Maintain professional presence |
| Resources | Is this useful reference or knowledge? | Notes about typography |
| Archive | Is it inactive or concluded? | Completed portfolio launch |

Inbox is a staging location when purpose or destination is unclear. It is not a fifth PARA category. A project does not need an invented deadline. A resource may support multiple projects; link to it instead of duplicating its body. Preserve the original kind when archiving and allow restoration.

Classify by how the user will use the information, not by document format. Keep an existing system's names and logical equivalents. Do not force a physical folder migration to apply the method.
